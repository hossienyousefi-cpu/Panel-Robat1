⚡ پنل مدیریت

سیستم مدیریت اینترنت هوشمند با پشتیبانی از ریسلر

⚠️ لطفاً قبل از استفاده، فایل includes/config.php را پیکربندی کنید.

📋 مراحل نصب

1
یک دیتابیس MySQL در cPanel ایجاد کنید
سپس محتویات فایل install.sql را اجرا کنید
2
فایل includes/config.php را باز کنید و مقادیر زیر را تنظیم کنید:
DB_HOST, DB_NAME, DB_USER, DB_PASS - اطلاعات دیتابیس
IBS_URL, IBS_ADMIN, IBS_PASS - آدرس و اطلاعات IBSng
3
رمز ادمین پیش‌فرض را با اجرای این کوئری تغییر دهید:
UPDATE admins SET password = '$2y$12$...' WHERE username='admin';
یا از phpMyAdmin استفاده کنید و رمز را با bcrypt hash کنید
4
برای تولید hash رمز عبور در PHP:
echo password_hash('رمز_جدید', PASSWORD_BCRYPT, ['cost' => 12]);
