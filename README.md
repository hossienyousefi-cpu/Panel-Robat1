# Panel Robat — سیستم جامع فروش سرویس اینترنت (IBSng + Reseller Panel + Telegram Bot)

این ریپازیتوری چهار بخش را پیاده‌سازی می‌کند که با هم یک سیستم فروش/مدیریت سرویس اینترنت را تشکیل می‌دهند:
ربات تلگرام مشتری نهایی (تسک ۱)، پنل Reseller (تسک ۲)، پنل ادمین (تسک ۳)، و یک پنل مدیریتی داخل همان ربات
تلگرام برای Export/Import دیتابیس و تغییر تنظیمات اتصال به‌صورت آنی (تسک ۴). پیش‌فرض معماری کلی:

```
[کاربر نهایی / Reseller]
        |
        v
 اینترنت (خارج یا داخل ایران)
        |
        v
+-------------------------+        SSH Tunnel (بدون هیچ پورت باز رو به اینترنت)      +--------------------------+
|   Host vaset             |  ------------------------------------------------->    |   Server IBSng            |
|   (Panel-vip.ir - VPS    |     فقط از vaset به IBSng، هیچ پورتی روی IBSng باز      |   (ایران‌اکسس، پشت فایروال) |
|    با کنترل‌پنل cPanel/WHM)|     نمی‌شود جز SSH خود سرور                            |                            |
|                          |                                                        |                            |
|  - پنل ادمین (PHP)        |                                                        |  - IBSng Agent (PHP، فقط    |
|  - پنل Reseller (PHP)     |  <---- HTTP/JSON روی تونل (127.0.0.1:PORT) ---------->  |    روی 127.0.0.1 گوش می‌دهد) |
|  - ربات تلگرام (Webhook)  |                                                        |  - از admin.php خودِ IBSng   |
|  - دیتابیس MySQL جداگانه  |                                                        |    برای انجام عملیات واقعی   |
|  - Cron Jobها             |                                                        |    استفاده می‌کند             |
+-------------------------+                                                        +--------------------------+
```

دلیل این معماری: سرور IBSng به‌عمد فقط از داخل ایران در دسترس است تا در برابر حملات از بیرون محافظت شود.
بنابراین هیچ درخواستی مستقیماً از اینترنت (یا حتی از هاست vaset) به‌صورت باز به سمت IBSng نمی‌رود؛
هاست vaset («Host vaset») از طریق یک تونل SSH که خودش به‌سمت سرور IBSng برقرار می‌کند، با یک سرویس کوچک
به‌نام **IBSng Agent** (که روی خود سرور IBSng و فقط روی `127.0.0.1` اجرا می‌شود) صحبت می‌کند. IBSng Agent هم
با تکرار همان مراحلی که خودتان دستی در پنل ادمین IBSng انجام می‌دهید (تب User → Add New User، Search User →
Lock و ...) عملیات واقعی را روی IBSng انجام می‌دهد. به این ترتیب هیچ منطق داخلی IBSng حدس زده یا دستکاری
مستقیم دیتابیس آن (به‌جز خواندن جدول استاندارد `radacct` برای تعداد آنلاین‌ها) انجام نمی‌شود.

## پوشه‌ها

- `vaset-host/` → کدی که باید روی Panel-vip.ir (Host vaset) دیپلوی شود: پنل ادمین، پنل Reseller، ربات
  تلگرام، دیتابیس اختصاصی سیستم، Cron Jobها.
- `ibsng-agent/` → کد بسیار کوچکی که باید **روی خودِ سرور IBSng** نصب شود (نیاز به SSH/root دارد) و فقط
  روی `127.0.0.1` گوش می‌دهد. این agent پل ارتباطی بین Host vaset و IBSng است.
- `docs/` → مستندات معماری، دیپلوی و مهم‌تر از همه راهنمای تطبیق IBSng Agent با نصب واقعی شما.

## قبل از هر کاری این را بخوانید

هرجا در کد به `VERIFY_ME` برخوردید (بیشتر در `ibsng-agent/config.php` و `ibsng-agent/src/IBSngAdminClient.php`)
یعنی آن بخش به فیلدهای دقیق فرم‌های پنل ادمین IBSng شما وابسته است. چون IBSng هیچ API رسمی ندارد، Agent با
شبیه‌سازی همان درخواست‌های HTTP که مرورگر شما هنگام کلیک روی «Add New User» یا «Edit» می‌فرستد کار می‌کند؛
نام دقیق فیلدها بین نسخه‌های مختلف IBSng ممکن است کمی فرق کند. مراحل استخراج این مقادیر با DevTools مرورگر
در `docs/IBSNG_INTEGRATION.md` به‌صورت قدم‌به‌قدم توضیح داده شده. بدون این تطبیق، بخش‌های خواندن اطلاعات
(تعداد آنلاین از `radacct`) کار می‌کنند ولی عملیات نوشتن (ساخت/حذف/لاک/تمدید یوزر) نیاز به این تنظیم دارند.

## شروع سریع

1. `docs/ARCHITECTURE.md` را بخوانید تا مدل داده و جریان مالی (بستانکاری/بدهکاری) را کامل متوجه شوید.
2. `docs/DEPLOYMENT.md` را برای نصب گام‌به‌گام روی Host vaset و سرور IBSng دنبال کنید.
3. `docs/IBSNG_INTEGRATION.md` را برای تطبیق IBSng Agent با نصب واقعی خودتان دنبال کنید.

## تسک ۴ به‌طور خلاصه

آدرس/کلید اتصال به IBSng Agent دیگر فقط در `.env` نیست؛ در دیتابیس هم قابل ذخیره است و از دو جا قابل تغییر:
پنل ادمین وب (`/admin/settings.php`) یا مستقیماً از داخل همان ربات تلگرام (وقتی Chat ID شما به‌عنوان ادمین
ثبت شده باشد، منوی مدیریتی به‌جای منوی مشتری باز می‌شود) — یعنی اگر اتصال قطع شد، بدون نیاز به SSH قابل
اصلاح است. از همان منو می‌توانید دیتابیس اختصاصیِ این سیستم (نه دیتابیس IBSng) را Export/Import هم بکنید؛
جزئیات کامل در `docs/ARCHITECTURE.md` بخش «تسک ۴».
